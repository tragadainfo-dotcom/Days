# День

Локальный журнал поручений для одного пользователя. В репозитории один файл приложения — index.html. Для записи в файл откройте его в Edge или Chrome. Установка, сервер и подключение к интернету для работы самого журнала не нужны.

Откройте приложение в Edge или Chrome и нажмите «Открыть файл журнала», чтобы выбрать существующий JSON. Для первого запуска без журнала нажмите «Создать файл». При создании в новый файл попадут прежние записи, если этот браузер ещё показывает их. После подключения приложение автоматически читает и сохраняет данные в выбранный файл. Подключение запоминается, пока браузер хранит разрешение. Если разрешение сброшено, выберите тот же JSON снова.

Чтобы видеть актуальные записи на другом ПК, выберите на нём тот же файл, доступный обоим компьютерам. Если приложение обнаружит изменения в файле перед сохранением, оно сообщит об этом. При одновременном редактировании с нескольких ПК у общей папки нет серверной координации, поэтому используйте по одному активному сеансу записи. Черновики писем копируются в рабочую почту вручную.

## Основные сценарии

- Новая запись создаётся прямо в строке таблицы. Tab переводит курсор в следующее поле. Enter или галочка сохраняет её и возвращает курсор в поле нового поручения. Основной ответственный и соисполнитель выбираются из выпадающих списков. Кнопка «Ответственные» открывает справочник. В него можно вставить столбец имён из Excel, по одному имени на строку.
- Срок можно изменить в ячейке таблицы. Нажмите «Изменить» у поручения, чтобы отредактировать карточку, включая название, даты, ответственных, статус и комментарий.
- Отметка о выполнении переносит поручение в раздел «Выполненные». Снятие отметки возвращает поручение в рабочий список.
- Доска и таблица работают с общим списком. Статус на доске можно менять перетаскиванием или из списка.
- Нажатие на заголовок столбца сортирует строки. Повторное нажатие меняет направление. На «Обзоре» показана статистика всех записей. На экране «Мой день» собраны личный план, просрочка, сроки на сегодня и наступившие даты контроля.
- Для проверки интерфейса используйте «Данные → Добавить примеры» в отдельном профиле браузера.

## Импорт Excel

Сохраните лист в Excel в формате CSV. «Данные → Импорт из Excel (CSV)» принимает столбцы «Поручение», «Срок», «Ответственный», «Комментарии» и «Выполнение». Для импорта достаточно столбца «Поручение». Ответственные из файла автоматически добавляются в справочник.

Даты принимаются в форматах ГГГГ-ММ-ДД, ДД.ММ.ГГГГ и ДД.ММ.ГГ (двузначный год относится к 2000–2099). В столбце «Выполнение» можно оставить пустую ячейку, поставить отметку «Да» или указать дату выполнения. Книги XLSX напрямую не импортируются.

Импорт повторно пропускает совпадения по названию, сроку, ответственным и комментарию. Приложение записывает импортированные поручения в подключённый файл. Для резервной копии используйте меню «Данные».
