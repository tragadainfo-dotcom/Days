# День

Локальный журнал поручений для одного пользователя. В репозитории один файл приложения — index.html. Откройте его в современном Chromium или Firefox. Установка, сервер и подключение к интернету для работы самого журнала не нужны.

Браузер хранит записи в текущем профиле. Для обычной работы открывайте один и тот же файл из одного и того же места в том же профиле. При смене пути, браузера или профиля скачайте копию на старом месте через «Данные → Скачать резервную копию» и загрузите её на новом. Копия дополняет журнал записями с новыми идентификаторами. Черновики писем редактируются в приложении и копируются в рабочую почту вручную.

## Основные сценарии

- Новая запись создаётся прямо в строке таблицы. Tab переводит курсор в следующее поле. Enter или галочка сохраняет её и возвращает курсор в поле нового поручения. Двух ответственных можно ввести через запятую.
- Нажмите название записи, чтобы указать отдельные даты исполнения, контроля и начала, следующее действие, комментарий и включить дело в план на сегодня.
- Доска и таблица работают с общим списком. Статус на доске можно менять перетаскиванием или из списка.
- На «Обзоре» показана статистика всех записей. На экране «Мой день» собраны личный план, просрочка, сроки на сегодня и наступившие даты контроля.
- Для проверки интерфейса используйте «Данные → Добавить примеры» в отдельном профиле браузера.

## Импорт Excel

Сохраните лист в Excel в формате CSV. Первая строка содержит заголовки. Минимальный столбец — «Поручение». Дополнительно распознаются «Срок», «Ответственный», «Соисполнитель», «Статус», «Следующий контроль», «Дата начала», «Следующее действие», «Комментарий» и «Дата выполнения». Даты принимаются в форматах ГГГГ-ММ-ДД и ДД.ММ.ГГГГ. Книги XLSX напрямую не импортируются.

Импорт CSV пропускает совпадения по названию, сроку и обоим ответственным. Полную копию журнала сохраняйте в JSON.
