# День

Локальный журнал поручений для одного пользователя. В репозитории один файл приложения — index.html. Откройте его в современном Chromium или Firefox. Установка, сервер и подключение к интернету для работы самого журнала не нужны.

Браузер хранит записи в текущем профиле. Для обычной работы открывайте один и тот же файл из одного и того же места в том же профиле. При смене пути, браузера или профиля скачайте копию на старом месте через «Данные → Скачать резервную копию» и загрузите её на новом. Копия дополняет журнал записями с новыми идентификаторами. Черновики писем редактируются в приложении и копируются в рабочую почту вручную.

## Основные сценарии

- Новая запись создаётся прямо в строке таблицы. Tab переводит курсор в следующее поле. Enter или галочка сохраняет её и возвращает курсор в поле нового поручения. Основной ответственный и соисполнитель выбираются из выпадающих списков. Кнопка «Ответственные» открывает справочник. В него можно вставить столбец имён из Excel, по одному имени на строку.
- Срок можно изменить в ячейке таблицы. Нажмите «Изменить» у поручения, чтобы отредактировать карточку, включая название, даты, ответственных, статус и комментарий.
- Отметка о выполнении переносит поручение в раздел «Выполненные». Снятие отметки возвращает поручение в рабочий список.
- Доска и таблица работают с общим списком. Статус на доске можно менять перетаскиванием или из списка.
- На «Обзоре» показана статистика всех записей. На экране «Мой день» собраны личный план, просрочка, сроки на сегодня и наступившие даты контроля.
- Для проверки интерфейса используйте «Данные → Добавить примеры» в отдельном профиле браузера.

## Импорт Excel

Сохраните лист в Excel в формате CSV. «Данные → Импорт из Excel (CSV)» принимает столбцы «Поручение», «Срок», «Ответственный», «Комментарии» и «Выполнение». Для импорта достаточно столбца «Поручение». Ответственные из файла автоматически добавляются в справочник.

Даты принимаются в форматах ГГГГ-ММ-ДД, ДД.ММ.ГГГГ и ДД.ММ.ГГ (двузначный год относится к 2000–2099). В столбце «Выполнение» можно оставить пустую ячейку, поставить отметку «Да» или указать дату выполнения. Книги XLSX напрямую не импортируются.

Импорт повторно пропускает совпадения по названию, сроку, ответственным и комментарию. Для полной копии поручений и справочника сохраняйте JSON. Импорт и хранение записей происходят в браузере.
